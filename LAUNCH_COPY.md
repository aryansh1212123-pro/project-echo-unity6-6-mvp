# Project Echo — launch copy drafts

These drafts announce the **public source-prototype release**. They do not claim a commercial Early Access release, a finished game, or a verified downloadable player build.

## Launch announcement

**Project Echo is open to the community.**

Project Echo is a Unity 6.6 life-simulation prototype about caring for an Echo and discovering how its needs, personality, relationships, and memories shape the choices it makes. The current vertical slice includes Sanctuary care, short Glass Jungle expeditions, a memory archive, relationship values, world discoveries, and a small Gene Forge.

The source project and setup instructions are public on GitHub: https://github.com/aryansh1212123-pro/project-echo-unity6-6-mvp. The repository now includes EditMode tests for Echo data validation and the Memory Archive filters, plus a CI workflow that runs those tests before a Windows build when Unity license secrets are configured.

This is an early source prototype—not a finished Steam Early Access release. A verified standalone build and broader play-testing are still in progress. If you have ideas about Echo personality, memory, relationships, exploration, or Sanctuary life, please suggest a feature here: https://github.com/aryansh1212123-pro/project-echo-unity6-6-mvp/issues/new?template=feature_request.yml

Open it with Unity 6.6 (`6000.6.8f1`), try the prototype, and help shape what Project Echo could become.
